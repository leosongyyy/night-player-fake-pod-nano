## 建议的适配顺序

> 原则：先"只读不写"，确认通信和数值正确，再动配置；每步都能单独回退。

1. **PMU 只读**：`pmu_init()` + 读 `0x00/0x01/0x34/0x35/0xA4`，串口打印。用万用表对电压（±20 mV）。
2. **PMU 按键**：GPIO49 下降沿中断 + 读 `0x49` 清位 + 打日志。确认短按/长按/按下/松开四类事件。
3. **PMU 上 UI**：状态栏电池电压 → 电量百分比 + 充电图标（注意 [pmu_axp2101.md](pmu_axp2101.md) §6.3 的融合算法，别直接上 `0xA4`）。
4. **低电策略**：把 S3 时代的"低电拒启 / 低电自动关机"接回 `power_service` / `boot_flow`（§6.5）。
5. **软关机**：`fake_shutdown` 的"等待断电"分支改成写 `0x10[0]=1`（§9，保留 deepsleep 作 A/B 兜底）。
6. **RTC**：`rtc_init()` → 读时间 → 状态栏显示 → 首次上电校时（见 [rtc_pcf85063a.md](rtc_pcf85063a.md) §8）。

## 上板前必须实测确认的问题

| # | 问题 | 影响 | 出处 |
| --- | --- | --- | --- |
| 1 | TS 引脚有没有接 NTC（读 `0x36/0x37` 是 0.5 V 还是 0 V） | 没接且悬空 → **可能充不上电** | PMU §12 |
| 2 | `0x27[1:0]` ONLEVEL 的 EFUSE 默认值 | 开机要按多久 | PMU §8.2 |
| 3 | IRQLEVEL 到底是"短按/长按 IRQ 分界"还是别的 | 固件长按判定 | PMU §8.2（手册未明确） |
| 4 | `0x22[1]` 是否默认使能 6 s 长按硬关机 | 关机兜底是否存在 | PMU §3.3 |
| 5 | E-Gauge `0xA4` 在 600 mAh 电池上的实际曲线 | 电量显示可信度 | PMU §6.2 |
| 6 | 电池内阻（静置/播放电压差） | 电压法负载补偿 | PMU §6.4 |
| 7 | RTC 晶振负载电容与 `CAP_SEL` 是否匹配 | 走时精度 | RTC §6 |

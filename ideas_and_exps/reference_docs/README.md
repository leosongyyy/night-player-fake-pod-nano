## 建议的适配顺序

> 原则：先"只读不写"，确认通信和数值正确，再动配置；每步都能单独回退。

1. ✅ **PMU 只读**：`axp2101_init()` + 读 `0x00/0x01/0x34/0x35/0xA4`，串口日志打印（自检代码已于 2026-11-14 移除）。
2. ✅ **PMU 按键**：GPIO49 下降沿中断 + `0x49` 短按/长按/按下/抬起 + 清位；`button_service` 据此做双键判定。
3. ✅ **PMU 上 UI**：状态栏 / 下拉控制中心显示电量百分比 + 充电图标（融合算法见 [pmu_axp2101.md](pmu_axp2101.md) §6.3）。
4. ✅ **低电策略**：已按 AXP2101 电量百分比接回 `power_service` / `boot_flow`（开机 <2% 提示 5 秒后关机；使用中 <5% 持续 60s 关机）。
5. ✅ **软关机**：`fake_shutdown` 已改为"正在关机... → 保存 → 写 `0x10[0]=1`"的真关机；充电界面拔电关机的真机流程已实测通过（`POWER_OPTIONS_AND_CHARGE_BOOT.md` §7）。
6. ✅ **RTC 读时间/首次校时**：`rtc_init()` → 读时间 → 无效时项目诞生日校时；✅ 状态栏时间显示（`ui/clock_display.c`）与手动校时 UI（`ui/time_date_popup.c`）、WiFi 对时已完成。

## 上板前必须实测确认的问题

| # | 问题 | 影响 | 出处 |
| --- | --- | --- | --- |
| 1 | TS 引脚有没有接 NTC（读 `0x36/0x37` 是 0.5 V 还是 0 V） | 没接且悬空 → **可能充不上电** | PMU §12 |
| 2 | `0x27[1:0]` ONLEVEL 的 EFUSE 默认值 | 开机要按多久 | PMU §8.2 |
| 3 | IRQLEVEL 到底是"短按/长按 IRQ 分界"还是别的 | 固件长按判定 | PMU §8.2（手册未明确） |
| 4 | `0x22[1]` 是否默认使能 6 s 长按硬关机 | 关机兜底是否存在 | PMU §3.3 |
| 5 | E-Gauge `0xA4` 在 600 mAh 电池上的实际曲线 | 电量显示可信度 | PMU §6.2 |
| 6 | 电池内阻（静置/播放电压差） | 电压法负载补偿 | PMU §6.4 |
| 7 | RTC 晶振负载电容与 `CAP_SEL` 是否匹配 | 走时精度 | RTC §6 |

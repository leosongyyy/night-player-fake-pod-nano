# 未来计划

按依赖顺序实现：**配置存储 → 播放设置页 → 随机算法 → 3 秒关机适配**，每项完成即烧录实测。

## 1. 配置存储（NVS）

把用户可调配置持久化到 NVS（`partitions.csv` 已有 nvs 分区），开机自动恢复：

| 配置 | 说明 |
|---|---|
| 音量 | 0~100，开机恢复 |
| 亮度 | 0~255，取代硬编码的 `DISPLAY_BRIGHTNESS_DEFAULT`（全黑启动流程不变，仅恢复值改为配置） |
| 播放位置 | **第几个列表 + 列表内第几首**（NightPlayer 同款设计），开机跳转到上次的歌 |
| 循环方式 | 全部 / 单曲 / 列表循环 |
| 睡眠定时器 | 上次设置的分钟数，到点伪关机 |

思路：新增 `core/storage/config_store` 封装 NVS 读写；播放位置由
`player_controller` 在切歌/暂停时保存、开机读取跳转（`player_controller.h`
已注明"后续再做 NVS 持久化"）。

## 2. 播放设置页面

`settings_page`（现为占位）实现：循环方式选择、音量、亮度、睡眠定时器、
恢复默认。修改立即生效并写 NVS（与通知栏现有滑块共用同一配置源）。

## 3. 神奇的随机算法

新增随机播放模式：

- Fisher-Yates 洗牌生成"待播队列"，一轮内**不重复、不遗漏**，播完重洗；
- 新轮次首曲避开上一轮末曲（不立即重复），可选最近 N 首记忆窗口；
- 种子用 `esp_random()`；队列位置随配置持久化，重启后继续。

## 4. 适配 3 秒关机芯片

成品机电源侧有长按 3 秒硬断电的关机芯片：

- 长按到 **2.5s** 固件主动伪关机：保存配置、优雅停播、关音频/DAC/触摸/SD，
  **但不关屏幕**；
- 3s 芯片断电，屏幕靠**断电自然熄灭**向用户展示"关机已完成"（主动关屏会
  让用户分不清是否真的关机）；
- 需 `button_service` 增加长按事件（2500ms 阈值可调），改造 `fake_shutdown`
  为"等待断电"模式（light sleep / 停 CPU 等断电，而非立即 deepsleep）；
- ⚠ 实测确认断电机制是否独立于 ESP32，以及 2.5s→3s 间保存 NVS/停外设
  耗时是否足够。
